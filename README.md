# Sitio web de VantTS

Software de gestión + IA para negocios — vantts.com.mx

- Las 6 páginas (`*.html`) se generan con `build_site.py`. Para cambiar contenido, edita `build_site.py` y corre `python build_site.py` en esta carpeta; no edites los HTML a mano.
- Estilos en `assets/style.css`, menú lateral en `assets/script.js`, logo y favicon en `assets/`.
- Publicado en Vercel (proyecto `vantts-sitio`): cada `git push` a `main` se publica solo.
